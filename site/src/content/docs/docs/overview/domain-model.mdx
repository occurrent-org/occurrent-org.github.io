Occurrent needs nothing from your domain model. Commands, events and state are your own types, and a domain function is a plain function from the events so far to the new events. These pages show how to shape that model so it plugs into the [application service](/docs/layer-1/application-service/), either with plain functions or with a [decider](/docs/overview/deciders/).
