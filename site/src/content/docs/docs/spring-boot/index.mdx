This chapter covers the Spring Boot starters and the annotations they read. They wire up the [layer 1](/docs/layer-1/) parts for you. Features that have an annotation of their own describe it at the end of their own section, for example [`@Projection`](/docs/spring-boot/projection-annotation/), [`@Saga`](/docs/spring-boot/saga-annotation/) and [`@Snapshot`](/docs/spring-boot/snapshot-annotation/).
