This section covers the Spring Boot starters and the annotations they read. They wire up the [layer 1](/docs/layer-1/) parts for you. Everything Spring Boot adds is here, and these pages link down to the layer 0 and layer 1 pages for the concepts.

* [Getting started with Spring Boot](/docs/overview/getting-started-spring-boot/) builds a first application.
* [Spring Boot starter](/docs/spring-boot/starter/) lists the starters and what you add to use them.
* [What the starter configures](/docs/spring-boot/what-the-starter-configures/) says what the starter sets up and turns on, compared with wiring the same parts yourself.
* [Subscription annotations](/docs/spring-boot/subscription-annotations/), [`@Projection`](/docs/spring-boot/projection-annotation/), [`@Saga`](/docs/spring-boot/saga-annotation/) and [`@Snapshot`](/docs/spring-boot/snapshot-annotation/) declare handlers, projections, sagas and snapshots.
* [Brokers with Spring Boot](/docs/spring-boot/brokers/) and [Testing with Spring Boot](/docs/spring-boot/testing/) cover the broker starters and tests.
* [Configuration properties](/docs/spring-boot/configuration-properties/) lists every `occurrent.*` property.
